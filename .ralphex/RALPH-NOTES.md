# `.ralphex/` — what we changed from Ralphex defaults (and why)

This dir was generated by `ralphex --init` (v1.5.1), then customized for the Ralph-loop pipeline. Design: `../docs/plans/2026-06-24-ralph-loop-pipeline.md`. Universal-vs-project seam: `../.ralph/config.yml`.

## Customizations vs embedded defaults

- **`config` → `external_review_tool = none`** — POC runs Ralphex's **native 5-agent review** only; thermo-nuclear runs **separately** in `/ralph-review` so we can compare them (`comparison.md`). **Prod:** flip to `codex` (gpt-5.5) or `custom` + `custom_review_script` → thermo-nuclear as the external must-pass gate.
- **`config` → `move_plan_on_completion = false`** — keep `docs/plans/issue-N.md` in place; `/ralph-review` and `/ralph-ship` reference it by stable path after the loop.
- **`prompts/task.txt`** — overrides the default with: (1) reads each task's `[tdd]`/`[direct]` title tag, (2) runs the project validation gate `lint && format:check && build && doctor` with **react-doctor hard-blocking**, (3) commits with no `Co-Authored-By` trailer (repo rule).
- **`agents/*.txt`** — unchanged (native review kept on purpose, for the comparison).

## Isolation: branch-based, NOT Docker, NOT worktree

- Ralphex's only built-in isolation is git **worktrees** (`use_worktree`). We **leave it off** — a worktree has no `node_modules` (npm workspaces aren't copied), so `lint`/`build`/`doctor` would fail until a fresh `npm install` every run.
- Isolation is the dedicated **`ralph/issue-N` branch**: every change is committed there and revertible, gated before it reaches `main`. No Docker sandbox needed for the agent.

## Running the loop

1. Bring up the test DB (Postgres + pgvector) for `[tdd]` tasks: `docker compose up -d postgres`.
2. Be on the prep branch: `git switch ralph/issue-N`.
3. `ralphex docs/plans/issue-N.md` — per-task commits land on `ralph/issue-N`; no auto-merge to `main` (gate #2 is a human merge).
4. Then `/ralph-review`.
